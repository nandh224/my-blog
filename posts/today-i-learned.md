클로드 코드로 이 블로그를 만들면서 HTML, CSS, JavaScript가 각각 어떤 역할을 하는지 다시 한번 정리해봤습니다.

## HTML — 구조

글의 제목, 날짜, 본문 같은 콘텐츠에 의미를 부여하는 뼈대 역할을 합니다. 이 블로그에서는 마크다운 파일을 빌드 스크립트가 읽어서 `<h1>`, `<time>`, `<article>` 같은 태그로 변환해줍니다. 태그 자체에는 색이나 크기 같은 꾸밈이 전혀 없고, "이건 제목이다", "이건 날짜다"라는 의미만 담고 있습니다.

## CSS — 스타일

같은 HTML이라도 CSS에 따라 완전히 다르게 보입니다. 이 블로그에서는 CSS 변수(`--bg`, `--text`, `--link` 등)로 색상을 관리해서, 라이트/다크 모드를 전환할 때 변수 값만 바꾸면 전체 색상이 한 번에 적용되도록 했습니다. `@media` 쿼리로 화면 크기에 따라 여백과 레이아웃을 조정하는 반응형 스타일도 CSS의 역할입니다.

## JavaScript — 동작

HTML과 CSS만으로는 "클릭했을 때 무언가 바뀌는" 상호작용을 만들 수 없습니다. 이 블로그의 다크모드 토글 버튼이 대표적인 예로, 버튼 클릭 이벤트를 감지해서 `data-theme` 속성을 바꾸고 `localStorage`에 저장해 다음 방문 때도 기억하게 하는 부분이 JavaScript의 역할입니다.

세 가지를 역할별로 나눠서 생각하니, 왜 프레임워크 없이도 충분히 블로그를 만들 수 있었는지 이해가 됐습니다.
