# 지침: 픽셀 아트 에디터 - Review 단계

너는 이 저장소(my-blog)의 Review 서브에이전트다. Build 단계와는 별개의 독립적인 검증을 수행하라
(Build 서브에이전트가 스스로 한 검증을 그대로 믿지 말고 직접 확인할 것).

## 배경

`/apps/pixel-art/`에 순수 HTML/CSS/JS로 16x16 픽셀 아트 에디터가 구현되어 있다:
- `index.html`, `style.css`, `editor.js`
- 계획 문서: `/apps/pixel-art/spec.md` (요구사항과 설계가 여기 정리되어 있다)

## 네 임무

1. `spec.md`를 읽고 요구사항을 파악한다.
2. `index.html`, `style.css`, `editor.js`를 꼼꼼히 읽고 코드를 검토한다:
   - spec.md의 설계(자료구조, 주요 함수, PNG 저장 방식, 조작 방식 등)와 실제 구현이 일치하는지
   - 버그 가능성이 있는 부분:
     - `cellFromPointerEvent`의 좌표 변환이 캔버스 CSS 확대 배율과 무관하게 항상 올바른 셀을
       가리키는지 (경계값, 범위를 벗어난 클릭 처리 포함)
     - 드래그 중 연속 칠하기가 같은 셀을 반복해서 불필요하게 다시 그리지 않는지, 반대로 빠르게
       움직였을 때 셀을 건너뛰어 빈 칸이 생기지 않는지
     - PNG 저장 시 업스케일 캔버스가 실제로 `imageSmoothingEnabled = false`를 사용해 흐려지지
       않는지, 미채색 칸이 정말 투명하게 나가는지(불투명한 배경색으로 채워지지 않는지)
     - 지우개 토글과 색상 선택이 서로 상태를 올바르게 전환하는지 (지우개 켠 채로 팔레트
       클릭 시 지우개가 꺼지는지 등 spec에 명시된 동작)
     - 터치 이벤트에서 `preventDefault`/`touch-action: none`으로 페이지 스크롤이 실제로
       막히는지
   - 라이트/다크 모드 CSS 변수가 누락 없이 정의되어 있는지, 반응형이 실제로 동작할지
   - 접근성이나 명백한 오탈자, 블로그로 돌아가는 링크 경로 등
3. **가능하다면 실제로 브라우저에서 동작을 확인한다.**
   - `apps/pixel-art/index.html`을 브라우저에서 열어(정적 서버를 그 폴더에서 임시로 띄워도 된다)
     다음을 확인:
     - 페이지가 정상 로드되고 캔버스와 팔레트가 보이는지
     - 마우스로 클릭/드래그해서 실제로 칠해지는지, 지우개가 동작하는지
     - "전체 지우기"가 동작하는지
     - "PNG로 저장" 클릭 시 실제로 파일 다운로드가 트리거되는지, 다운로드된 PNG를 열어서
       (가능하면) 칠한 색이 올바른 위치에 업스케일되어 있고 미채색 부분이 투명한지 확인
     - 콘솔에 JS 에러가 없는지
   - 브라우저 자동화 도구를 쓸 수 없는 환경이라면, Node.js로 `editor.js`의 순수 로직 함수들
     (DOM에 의존하지 않는 좌표 계산 등)을 발췌해 별도 테스트 스크립트로 검증하되, 이 경우
     PNG 저장 관련 로직은 가능한 범위까지만(예: node의 canvas 없이 검증 어려운 부분은 정적
     코드 리딩으로) 확인하고 review.md에 한계를 명시하라.
4. 발견한 문제를 심각도와 함께 정리하고, **간단히 고칠 수 있는 문제라면 네가 직접 수정한다**
   (파일: `apps/pixel-art/index.html`, `apps/pixel-art/style.css`, `apps/pixel-art/editor.js`만
   수정 가능). 구조적으로 큰 재작업이 필요한 문제라면 고치지 말고 review.md에 남겨서 보고만 하라.
5. 검토 결과를 `/apps/pixel-art/review.md`에 작성한다. 포함할 내용:
   - 검증 방법(브라우저 실행 여부, 어떤 시나리오를 확인했는지)
   - 발견한 문제 목록 (심각도: 치명적/경미/제안)
   - 수정한 문제와 수정 내용
   - 남아있는(수정하지 않은) 이슈가 있다면 이유와 함께 명시
   - 최종 결론: 이 에디터가 정상 동작한다고 판단하는지

## 제약

- 수정 가능한 파일: `apps/pixel-art/index.html`, `apps/pixel-art/style.css`,
  `apps/pixel-art/editor.js`, 그리고 결과 보고서 `apps/pixel-art/review.md`.
- 그 외 어떤 파일도 건드리지 마라 (`spec.md`, 지침 파일들, `/apps/2048/`, 블로그 다른 파일 포함).
- 요구사항에 없는 새 기능을 추가하지 마라. 버그 수정과 명백한 오류 교정만 한다.

## 완료 후

review.md에 무엇을 적었는지, 수정한 문제가 있다면 무엇인지 요약해서 보고하라.
