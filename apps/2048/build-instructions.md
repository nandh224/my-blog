# 지침: 2048 게임 - Build 단계

너는 이 저장소(my-blog)의 Build 서브에이전트다. 아래 범위 내에서만 작업하라.

## 배경

my-blog는 마크다운 블로그 + 미니 웹앱 포트폴리오 프로젝트다. 프레임워크 없이 순수 HTML/CSS/JS만
사용한다 (CDN 라이브러리는 허용하나 이번 앱에서는 불필요하다고 이미 결론남).

Plan 단계에서 계획 문서 `/apps/2048/spec.md`가 이미 작성되었다. 먼저 이 문서를 읽고 그 내용을
그대로 구현하라.

## 네 임무

`spec.md`의 계획에 따라 실제 게임을 구현한다:

- `/apps/2048/index.html`
- `/apps/2048/style.css`
- `/apps/2048/game.js`

spec.md에 정의된 파일 구조, 게임 로직(자료구조/주요 함수), UI/UX, 조작 방식, localStorage 사용
범위를 충실히 따른다. 특히:

- 4x4 그리드, 방향키로 타일 밀기/병합, 랜덤 타일 생성(90% 2 / 10% 4), 게임 오버·승리 판정
- 점수판(현재 점수 + localStorage 기반 최고 점수)
- 키보드(방향키) + 모바일 터치 스와이프 조작을 같은 이동 로직으로 공유
- 라이트/다크 모드 대응 CSS 변수, 모바일 반응형
- 새 게임 버튼, 게임 오버/승리 오버레이

spec.md의 "9. 범위 밖"에 명시된 항목(리더보드 서버, 계정, undo, 이동 애니메이션 고도화, 진행 상태
저장/복원)은 구현하지 마라.

## 제약 (중요)

- **`/apps/2048/` 폴더 안의 파일만 생성/수정한다.** (`index.html`, `style.css`, `game.js`)
- `/apps/2048/spec.md`, `/apps/2048/plan-instructions.md`, `/apps/2048/build-instructions.md`는
  수정하지 마라.
- 이 폴더 밖의 어떤 파일도 건드리지 마라 — `src/build.js`, `src/templates.js`, `CLAUDE.md`,
  블로그의 다른 어떤 파일도 포함된다. (블로그 메인 페이지 연동은 별도의 Embed 단계에서 처리한다.)
- 프레임워크(React/Vue 등) 사용 금지. 순수 HTML/CSS/JS만 사용.
- 불필요한 추상화, 설정 옵션, 과도한 주석을 추가하지 마라. 주석은 자명하지 않은 이유(WHY)가
  있을 때만 최소한으로 작성한다.

## 완료 후

무엇을 만들었는지, spec.md의 계획과 다르게 구현한 부분이 있다면(있어서는 안 되지만 불가피한 경우)
그 이유를 요약해서 보고하라.
